# FocusFlow — 任务驱动的专注计时工具

FocusFlow 是一个轻量级个人效率 Web 应用。它采用“先选任务，再开始计时”的流程：用户先选择任务类型，再选择具体任务，最后进入该任务的计时页面。所有数据保存在浏览器本地，无需后端与账号。

## 核心功能

### 任务管理
- **任务类型入口**：首页先展示学习、工作、生活、运动、其他五种类型，选择类型后只展示对应任务。
- **新建 / 编辑任务**：可修改任务标题、所属类型与优先级。
- **优先级标记**：高 / 中 / 低三档，带颜色标签，列表内高优先级自动靠前。
- **完成标记**：可将任务标记为完成（置灰、划线、不参与计时），也可恢复为进行中。
- **手动排序**：同优先级任务支持上移、下移调整顺序。
- **删除任务**：删除任务不会清除历史专注记录。
- **任务累计**：每个任务独立累计专注时长和完成轮次。

### 专注计时
- **正计时**：从 `00:00:00` 开始向上计时，适合不确定任务耗时的场景。
- **倒计时**：支持 15、25、45、60 分钟预设，也支持 1–600 分钟自定义时长；倒计时归零后自动保存本轮记录。
- **计时控制**：支持开始、暂停、继续、重置，以及手动结束并保存本轮专注。
- **结束提示音**：使用 Web Audio 合成提示音，无需外部音频文件，可随时开关。
- **桌面通知**：倒计时结束后可弹出浏览器桌面通知（需授权），可随时开关。
- **番茄休息循环**：开启后，一轮倒计时结束自动进入 5 分钟休息倒计时，休息结束再次提醒。
- **全局快捷键**：计时页内按 `空格` 开始 / 暂停，`R` 重置，`E` 结束并保存。
- **标签页倒计时**：计时进行时浏览器标签标题实时显示剩余 / 已用时间。

### 专注记录与统计
- **专注记录**：按任务记录每轮专注模式、实际时长和完成时间，并显示今日累计专注分钟数。
- **连续专注天数**：顶部展示当前连续有记录的天数（今天暂无记录时从昨天起算，避免新一天被误判中断）。
- **每日统计**：汇总当天专注总时长、专注轮次、单次平均时长，并按小时展示专注时段分布。
- **每周统计**：按周一至周日汇总每日专注时长，展示本周总时长、轮次、日均时长、专注天数和最佳专注日。
- **每月统计**：展示近 6 个月的专注趋势、月度总时长、轮次、月均时长和最高效月份。
- **时间可视化**：通过柱状图和任务类型进度条，直观比较不同时间段与任务类别的投入。

### 数据与界面
- **本地持久化**：使用浏览器 `localStorage` 保存任务、专注记录与界面设置，刷新页面后仍可查看；旧版本数据自动兼容迁移。
- **备份导出 / 导入**：可一键导出 JSON 备份文件，或选择备份文件恢复全部数据。
- **深浅色模式**：支持浅色 / 深色主题切换，选择会被记忆。
- **响应式界面**：适配桌面端、平板和手机。

## 操作说明

- **新建任务**：任务列表右上角「新建任务」，选择类型、优先级并填写标题。
- **编辑 / 删除 / 排序 / 完成**：点击任务卡片右侧对应图标按钮；点击卡片主体进入计时页。
- **开始专注**：进入任务后选择正计时或倒计时，点击「开始专注」。
- **桌面通知授权**：在计时页勾选「结束桌面通知」后，按浏览器提示允许权限。
- **备份**：首页顶部云朵图标可导出或导入 JSON 备份。

## 设计思路

项目使用原生 HTML、CSS 和 JavaScript 实现，不依赖第三方框架、构建工具或后端服务。

1. **任务类型优先**：以任务类别作为首页一级入口，避免用户一打开应用就面对计时器或杂乱的任务清单。
2. **任务作为计时上下文**：点击具体任务后才进入专注界面，确保每段时间都关联到一个明确任务。
3. **计时策略分离**：正计时记录实际经过时间；倒计时根据用户设定的时长递减，两种模式共用开始、暂停、重置和保存机制。
4. **数据按任务归档**：每次专注生成一条记录，同时更新对应任务累计时长与专注轮次。
5. **本地状态管理**：任务、专注记录和界面设置保存在 `localStorage`。
6. **统计可视化**：统计面板支持每日、每周、每月切换；每日按小时分布，每周按星期分布，每月按自然月汇总，并提供任务类型占比。

所有数据只保存在当前浏览器，不会上传到服务器。清除浏览器站点数据会删除本地记录，建议定期使用导出备份。

## 运行方式

无需安装依赖，也无需配置数据库：

1. 下载或克隆本仓库。
2. 双击打开 `index.html`，或使用 VS Code 的 Live Server 插件运行。
3. 在首页选择任务类型，点击某个具体任务。
4. 选择正计时或倒计时，开始专注。

## 技术栈

- HTML5
- CSS3（Grid、Flexbox、响应式设计、CSS 变量深浅色主题）
- 原生 JavaScript（DOM、Events、Timer API、Web Audio、Notification API、FileReader / Blob）
- Browser `localStorage`
