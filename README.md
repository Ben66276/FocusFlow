# FocusFlow — 任务驱动的专注计时工具

FocusFlow 是一个轻量级个人效率 Web 应用。它采用“先选任务，再开始计时”的流程：用户先选择任务类型，再选择具体任务，最后进入该任务的计时页面。

## 核心功能

- **任务类型入口**：首页先展示学习、工作、生活、运动、其他五种类型，选择类型后只展示对应任务。
- **具体任务管理**：可新增具体任务；每个任务独立累计专注时长和完成轮次。
- **正计时**：从 `00:00:00` 开始向上计时，适合不确定任务耗时的场景。
- **倒计时**：支持 15、25、45、60 分钟预设，也支持 1–600 分钟自定义时长；倒计时归零后自动保存本轮记录。
- **计时控制**：支持开始、暂停、继续、重置，以及手动结束并保存本轮专注。
- **专注记录**：按任务记录每轮专注模式、实际时长和完成时间，并显示今日累计专注分钟数。
- **每日统计**：汇总当天专注总时长、专注轮次、单次平均时长，并按小时展示专注时段分布。
- **每周统计**：按周一至周日汇总每日专注时长，展示本周总时长、轮次、日均时长、专注天数和最佳专注日。
- **每月统计**：展示近 6 个月的专注趋势、月度总时长、轮次、月均时长和最高效月份。
- **时间可视化**：通过柱状图和任务类型进度条，直观比较不同时间段与任务类别的投入。
- **本地持久化**：使用浏览器 `localStorage` 保存任务与专注记录。
- **响应式界面**：适配桌面端、平板和手机。

## 设计思路

项目使用原生 HTML、CSS 和 JavaScript 实现，不依赖第三方框架、构建工具或后端服务。

1. **任务类型优先**：以任务类别作为首页一级入口，避免用户一打开应用就面对计时器或杂乱的任务清单。
2. **任务作为计时上下文**：点击具体任务后才进入专注界面，确保每段时间都关联到一个明确任务。
3. **计时策略分离**：正计时记录实际经过时间；倒计时根据用户设定的时长递减，两种模式共用开始、暂停、重置和保存机制。
4. **数据按任务归档**：每次专注生成一条记录，同时更新对应任务累计时长与专注轮次。
5. **本地状态管理**：任务和专注记录保存在 `localStorage`，刷新页面后仍可查看。
6. **统计可视化**：统计面板支持每日、每周、每月切换；每日按小时分布，每周按星期分布，每月按自然月汇总，并提供任务类型占比。

所有数据只保存在当前浏览器，不会上传到服务器。清除浏览器站点数据会删除本地记录。

## 运行方式

无需安装依赖，也无需配置数据库：

1. 下载或克隆本仓库。
2. 双击打开 `index.html`，或使用 VS Code 的 Live Server 插件运行。
3. 在首页选择任务类型，点击某个具体任务。
4. 选择正计时或倒计时，开始专注。

## 技术栈

- HTML5
- CSS3（Grid、Flexbox、Responsive Design）
- 原生 JavaScript（DOM、Events、Timer API）
- Browser `localStorage`
